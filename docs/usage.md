# Using Test Module

## Requirements

- Foundry VTT version 14 or later.

## Installation

In Foundry's **Add-on Modules** tab choose **Install Module** and paste the manifest URL:

```
https://github.com/Mondarth/test-module/releases/latest/download/module.json
```

Then enable **Test Module** in your world under **Manage Modules**.

## Settings

The module has no settings yet.

## The API

The module has no public API yet.
